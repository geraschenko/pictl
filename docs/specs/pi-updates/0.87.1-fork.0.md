# Bundled pi update: 0.84.3-fork.0 → 0.87.1-fork.0

Status: implemented and verified; ready for review.

# SPEC

Migrate the bundled fork from 0.84.3-fork.0 to 0.87.1-fork.0 while preserving the dependency range policy and raw transcript semantics.

Approved scope and success criteria:

- Expose audited `clear-queue --target … [--raw]`, returning pi's cleared steering/follow-up arrays.
- Render system messages (including section/tool-only changes), usage entries, and context-edit omit/replace entries explicitly in entries and tree output.
- Match upstream `pi-*` filters: hide usage even in `pi-all`; classify context edits as bookkeeping. Preserve pictl's conversation filter and unfiltered usage output.
- Accept and complete thinking level `max` (an approved pre-existing gap).
- Audit context projection, lifecycle, and streaming assumptions; hold projection changes until their semantics are established. Preserve raw history rather than silently rewriting earlier messages.
- Add focused regressions and pass type, lint, formatting, test, and build checks. Verify isolated provider-free startup, socket/state, shutdown, and persisted-session revival; record any unavailable checks and residual risks.

Non-goals: optional refactors, fork changes, credential access, paid provider calls, and modifying existing agents.

## Implementation-Time Decisions

### Preserve append-history projection

Kept the existing per-entry converter rather than adopting `buildSessionProjection`: the latter would apply context edits and discard inactive/compacted history, contrary to the approved existing formatting spec. Added tests for the distinction. Actual provider context stays pi-owned via `get_messages`.

### Share system-message rendering

The message formatter returned `undefined` for system messages, silently dropping them without a type error because its return type permits omission. A shared formatter preserves section contents and lists section/tool updates in message output; entry and tree views reuse it as a single-line summary. This avoids fixing only the compiler-visible paths.
